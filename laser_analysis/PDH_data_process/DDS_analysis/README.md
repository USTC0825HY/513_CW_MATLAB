# DDS 异常复位工况相位分析说明

本目录用于定量分析 FPGA 中 DDS 相位累加器被周期性异常复位时的行为。当前程序为：

- `DDS_analysis_phase_use.m`

程序在 48 bit 相位字层面同时模拟一个正常连续运行的 DDS 和一个受异常复位状态机控制的 DDS，比较每次复位后两者的稳态相位差，并将短时仿真得到的单周期相位步进外推到 1 小时，用于判断该异常是否会造成不可跟踪的长期相位发散。

## 1. 分析背景与工程目的

异常工况下，DDS 每隔 10 ms 收到一次复位请求。但该复位不是常见的“复位有效后立即清零”，而是以下特殊流程：

1. 相位累加器在复位窗口内继续运行；
2. 等待累加器自然溢出后清零；
3. 清零后保持到 32 个时钟的复位窗口结束；
4. 进入 10 个时钟的固定相位等待区；
5. 随后恢复正常相位累加。

分析的核心不是判断异常是否存在，而是确定异常的影响边界：

- 复位暂态是否只造成局部波形缺损或短暂盲区；
- 每次恢复后是否仍具有可预测的相位关系；
- 微小相位误差会保持有界、缓慢漂移，还是快速绕转；
- 上位机载波恢复、数字解调或 PLL 是否能够跟踪并补偿；
- 是否必须立即修改 FPGA 固件并重新完成综合、布局布线和时序验证。

因此，本程序将“复位附近的暂态损伤”和“复位后的长期稳态相干性”分开评估，为软硬件修正方案提供定量依据。

## 2. 当前模型参数

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `Fs` | 100 MHz | DDS 系统时钟 |
| `FPGA_DDS` | `0x1C36113404E8` | 48 bit 频率控制字 FTW |
| `N_total` | `2^48` | 相位累加器模数 |
| `reset_interval` | 1,000,000 clocks | 复位间隔，即 10 ms |
| `reset_persist` | 32 clocks | 复位窗口长度 |
| `reset_to_start` | 10 clocks | 复位撤去后的固定等待时间 |
| `stable_offset` | 142 clocks | 每个复位周期内的相位采样位置 |
| `num_periods` | 15 | 进行逐时钟仿真的复位周期数 |

FTW 对应的实际 DDS 频率为：

```text
f_DDS = FTW / 2^48 × Fs
      = 11,019,999.999999186 Hz
```

它非常接近 11.02 MHz，但仍保留由有限位宽导致的微小频率量化误差。

## 3. 程序的时序模型

### 3.1 正常 DDS

正常 DDS 在每个时钟执行一次模 `2^48` 累加：

```matlab
reg_acc_normal = mod(reg_acc_normal + FPGA_DDS, N_total);
```

它不受复位异常影响，作为理想连续相位参考。

### 3.2 故障 DDS

程序用 `cycle_idx = mod(t - 1, reset_interval)` 表示当前时钟在一个复位周期内的位置。

- `cycle_idx = 0...31`：处于复位窗口。累加器先继续运行，检测到自然溢出后清零，并在窗口剩余时间保持为零；
- `cycle_idx = 32...41`：每个时钟都将累加器固定为一个 FTW；
- `cycle_idx >= 42`：恢复正常模累加。

当前 FTW 较大，一个自然相位周期约为 9.07 个系统时钟，因此可以在 32 个时钟的复位窗口内遇到溢出。若以后更换为较小的 FTW，应重新确认 32 个时钟内是否一定会发生溢出，否则当前状态机模型可能无法完成清零。

### 3.3 稳态采样

程序在每次复位开始后的第 142 个周期位置采样，此时已越过 32 个复位时钟、10 个等待时钟，并额外运行了 100 个时钟。采样量为正常 DDS 与故障 DDS 的 48 bit 相位字差，随后换算为角度。

前 15 个复位周期采用逐时钟整型仿真，总计运行 15,000,000 个系统时钟。使用 `uint64` 的目的是避免长时间累加过程中由双精度浮点数带来的相位字舍入误差，使关键状态更新与 FPGA 的整数累加行为保持一致。

## 4. 当前结果及其物理含义

使用 MATLAB R2025a 运行当前脚本，得到：

```text
首次稳态采样的绝对相位差： 186.551999999880°
相邻复位周期的相位步进：  -0.000002930392°/次
1 小时复位次数：           360000 次
报告的 1 小时累计相移：   -1.054941094480°
```

初始相位差约为 `186.552°`，来自正常 DDS 和重启后的故障 DDS 之间确定的有效累加时钟差。在当前采样时序下，该差值等价于 41 个 FTW：

```text
Δφ_initial = mod(41 × FTW, 2^48) × 360° / 2^48
           = 186.552°
```

每个 10 ms 周期包含恰好 1,000,000 个时钟。FTW 在这一时间内理论上对应 110,200 个载波周期，但由于 48 bit FTW 的量化，整数相位字还残留：

```text
signed(mod(1,000,000 × FTW, 2^48)) = -2,291,200 LSB
```

换算为相位即：

```text
Δφ_step = -2,291,200 × 360° / 2^48
         = -2.930391929 × 10^-6 °/次
```

每秒发生 100 次复位，因此按 360,000 个周期计算，一小时累计变化约为：

```text
Δφ_1h = 360000 × Δφ_step
       ≈ -1.054941094°
```

这说明当前参数下的稳态相位不是严格不变，而是以极低速率单向漂移。该结果支持如下工程判断：复位附近存在确定的暂态破损，但复位后的相位关系仍然高度可预测；约 1°/h 的缓慢变化通常比快速相位绕转更容易被上位机相位跟踪或载波恢复环路吸收。能否实际补偿仍取决于环路带宽、复位盲区内的数据处理方式以及允许的误码率，不能仅凭相位漂移数值作最终判定。

## 5. 图形输出

程序生成一张包含两个子图的窗口：

1. **微观视图**：显示前 15 次复位稳定后的绝对相位差，用于确认相邻周期的微小固定步进；
2. **宏观视图**：将上述步进外推到 1 小时，显示绝对相位差的长期变化趋势。

宏观曲线是基于短时整数流水仿真得到的固定步进进行解析外推，并非逐时钟仿真完整的 1 小时。这样既保留了底层相位字仿真的可信度，也避免执行约 `3.6×10^11` 次时钟循环。

## 6. 运行方法

在 MATLAB 中将工作目录切换到工程根目录，然后执行：

```matlab
run(fullfile('DDS_analysis', 'DDS_analysis_phase_use.m'));
```

也可以直接进入 `DDS_analysis` 目录后运行：

```matlab
DDS_analysis_phase_use
```

程序会在命令行输出定量报告，并生成微观和宏观相位趋势图。

## 7. 使用结果时的注意事项

### 7.1 当前结论只对应 `reset_interval = 1e6`

当前代码并未使用 `1e6 - 1`。将复位间隔减少一个系统时钟，会额外引入接近一个 FTW、约 `39.672°` 的单周期相移，不再是当前的百万分之三度级步进。因此，`-1.05°/h` 结论不能直接用于 `reset_interval = 999999` 的版本。

### 7.2 无符号减法的适用范围

当前程序使用：

```matlab
mod(reg_acc_normal - reg_acc_faulty, N_total)
```

MATLAB 的 `uint64` 减法在负结果处会饱和为零，而不是自动实现模减法。当前参数和采样区间内，正常相位字大于故障相位字，因此运行结果没有受到影响；如果改变 FTW、采样位置或仿真时长，应将相位差改为显式的安全模减法。

### 7.3 需要统一“一小时累计量”的计数口径

长期曲线以第一次采样为起点，第 360,000 个采样点与第一次采样之间实际相隔 359,999 个复位周期；命令行报告则使用 360,000 个步进。两种口径仅相差约 `2.93×10^-6°`，不影响当前工程结论，但正式引用结果时应明确参考时刻并统一定义。

### 7.4 相位跨越 0°/360°时需要展开

当前相邻步进通过两个角度直接相减得到。若修改参数后相位恰好跨越 0°/360°边界，直接相减可能出现接近 360°的假跳变。此时应先将相位增量包裹到 `[-180°, 180°)`，长期分析则使用展开后的连续相位。

### 7.5 必须与真实 RTL 时序核对

模型假定复位窗口内“等待自然溢出后清零”，并在随后的 10 个时钟内持续将相位字固定为 FTW。如果真实 RTL 使用时钟使能、同步清零、不同的优先级，或只在等待结束时装载一次 FTW，应按实际寄存器传输时序修改模型。该脚本给出的是当前状态机假设下的确定性结果，而不是脱离 RTL 实现的普遍结论。

## 8. 工程结论

在当前 100 MHz 时钟、48 bit FTW、10 ms 复位间隔和既定复位状态机下：

- 每次异常复位都会产生局部暂态和固定等待区；
- 稳态恢复后的绝对相位偏置约为 `186.552°`；
- 相邻复位之间存在约 `-2.93×10^-6°` 的确定性慢漂；
- 按当前报告口径，一小时累计相移约为 `-1.05°`；
- 长期相位变化是缓慢且可预测的，但复位暂态造成的数据损失仍需由接收链路单独评估。

该结果可以作为评估上位机补偿能力、PLL 跟踪裕量和 FPGA 固件修复优先级的定量参考。
