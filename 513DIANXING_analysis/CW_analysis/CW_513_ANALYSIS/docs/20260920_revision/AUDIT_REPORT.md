## 十六进制与CSV读取

公共入口为`converter.io.readAdcCsv`，交互预检为`prepareAdcRadix`，判定规则为`resolveAdcInputRadix`。

- `inputRadix`支持`auto`、`hex`、`decimal`。显式设置优先。
- `auto`只采信CSV明确声明、`0x`前缀或含负号的合法十进制列。纯数字`1000`和无前缀`03e8`不猜测；交互运行要求用户选择，显式非交互运行报错。
- 只解析配置指定的ADC列；样本号、valid列和无关总线列不会被当成十六进制。
- 16位补码按阈值减`2^16`；ADC128仍按12位unsigned读取并减半量程居中。缺失、非法、小数、NaN/Inf、混合基数和超位宽码直接拒绝，不删点。
- `evidence/input_decoding.csv`记录实际基数、判定来源、列号、位宽、码制、转换规则、源样点数和保留样点数。

23项定向读取测试覆盖`0000/7FFF/8000/FFFF`、12/14/16位边界、纯数字歧义、指数形式、非法输入、valid抽取、131072点记录、交互选择复用、多文件解码记录追加和双通道表头按所选数据列识别。
