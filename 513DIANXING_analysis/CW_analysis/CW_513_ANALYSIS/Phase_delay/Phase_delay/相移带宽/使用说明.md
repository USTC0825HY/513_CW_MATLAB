# 相移带宽批量分析

## 新增：5% 阈值补充计算

在上一级 `Phase_delay` 目录中运行 `summary = run_bandwidth_5pct;`，将生成 `results/5pct/5%阈值延迟分析报告.md` 和每条路径的 5%/10%/50% 对照图、CSV、MAT、FIG。5% 定义为各通道稳态阶跃幅度的 5%，不是示波器满量程的 5%。输入基线噪声会多次超过该阈值，因此采用 50% 边沿前最后一次向上穿越 5% 的交点，并输出噪声诊断与原始采样点放大图。

## 原有：10% / 50% 批量计算

在 MATLAB 中将上一级 `Phase_delay` 设为当前目录，运行：

```matlab
summary = run_bandwidth_batch;
```

程序按文件名配对本目录顶层的 `.mat` 与 `.bode3`。MAT 是示波器波形，A 为输入、B 为输出；Bode3 中读取保存的复数频响。全部计算和绘图在 MATLAB 中完成。

结果位于 `results`：

- `相移带宽分析报告.md`：含方法、汇总表、每条路径的阈值时刻与图片。
- `batch_summary.csv`：两种延迟、两种校正的 −45° 频率、幅值 −3 dB 频率等。
- 每条路径子目录的 `corrected_bandwidth.png/.fig`：幅值与两种校正相位同图双纵轴，使用适合校正相位的刻度，标注 −45° 交点。
- `phase_corrected.png/.fig`：同时显示原始相位，便于比较扣除前后结果。
- `phase45_summary.csv`：两种校正的首次下降 −45° 频率（Hz）与下降交点数量。
- `scope_delay.png/.fig`、`delay_summary.csv`：波形与 10%/50% 延迟。
- `bode_extracted.mat`：从 Bode3 读取并计算的频响表，变量名为 `bodeData`。

−45° 频率在相邻实测点间按对数频率插值；NaN/未观测到表示扫描内没有下降交点，不能视为无限带宽。所有交点以扣除各自阈值延迟后的相位计算。

`line.psdata` 尚无对应 MAT，因此没有计算 line 的阈值延迟，也没有从各路径中扣除 line 参考。原始文件保持不变；再次运行会更新同名结果和自动报告。

单路径或自定义窗口分析可调用上级目录的 `analyze_phase_delay`，`BodeFile` 既支持原有 Bode CSV，也支持本批 `.bode3` 格式。详细参数见上级目录 `代码使用说明.md`。
