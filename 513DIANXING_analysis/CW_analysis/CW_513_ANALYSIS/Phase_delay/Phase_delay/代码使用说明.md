# MATLAB 幅频、相频与延迟分析程序使用说明

## 1. 程序功能与运行环境

本程序读取 Bode100 导出的幅频/相频 CSV，以及 PicoScope 导出的 MAT 或 CSV 波形，完成：

- 幅频与相频绘图，共用频率横轴，使用左右双纵轴。
- 输入、输出完整波形及阈值附近的归一化波形绘图。
- 10% 和 50% 阈值延迟计算。
- 分别扣除两种常数延迟对应的相移，并与原始相位比较。
- 保存 PNG 图片、可编辑 MATLAB FIG、CSV 数值和 MAT 分析结果。

程序已在 **MATLAB R2025a** 中运行验证，未使用额外工具箱。代码采用较新的名称-值参数语法，旧版 MATLAB 的兼容性未验证。现有 MAT 已完成转换，日常分析不需要 Python 或 PicoScope 软件。

## 2. 本次数据：一键运行

在 MATLAB 中打开 `Phase_delay` 文件夹，将它设为当前文件夹，运行：

```matlab
run_JG22_JG18
```

也可直接打开 `run_JG22_JG18.m`，点击“运行”。该脚本按自身所在位置寻找数据，因此从编辑器运行时不依赖当前工作目录。

脚本自动使用：

| 项目 | 配置 |
|---|---|
| Bode 文件 | `JG22-JG18_2026-09-10T11_54_13.csv` |
| 示波器文件 | `JG22-jg18.mat` |
| 输入 | A，按通道 1 为输入处理 |
| 输出 | B，按通道 2 为输出处理 |
| 平台区间 | 全记录首尾各 15% |
| 平滑 | 不平滑 |
| 输出目录 | `Phase_delay/results` |

MATLAB 会显示图窗、在命令窗口打印延迟表，并在工作区留下 `results` 变量。本次应得到约 **246.62 ns（10%）** 和 **262.36 ns（50%）**。

> 输入/输出顺序应与实际接线一致。目前按波形中 A 先跳变、B 后响应采用 A 输入、B 输出。若接线不同，请修改脚本，不能仅根据编号认定方向。

重复运行会更新输出目录中的同名结果文件。原始 CSV、MAT 不会被修改；需要保留不同参数的结果时，请设置不同的 `OutputDir`。

## 3. 分析其他数据

确保程序文件夹已在 MATLAB 路径中。以下示例默认当前目录为 `Phase_delay`；示例中的新文件名需要替换为实际文件名。

### 3.1 指定 Bode CSV 和示波器 MAT

```matlab
r = analyze_phase_delay( ...
    BodeFile="new_bode.csv", ...
    ScopeFile="new_scope.mat", ...
    InputChannel="A", ...
    OutputChannel="B", ...
    OutputDir="results_new");
```

文件也可以使用绝对路径。如果当前目录不在程序文件夹，先用 `addpath` 将程序文件夹加入 MATLAB 路径。

### 3.2 只提取幅频和相频

```matlab
r = analyze_phase_delay(BodeFile="JG22-JG18_2026-09-10T11_54_13.csv");
```

未指定 `ScopeFile` 时，程序保存 Bode 图和 CSV，然后提示缺少示波器数据。这是正常的部分分析模式，此时不会新生成延迟表、校正相位或完整 `analysis.mat`。若输出目录已有以前的延迟结果，这些旧文件仍会保留，注意不要当作本次输出。

不指定 `BodeFile` 时，程序在代码所在目录的顶层寻找包含 Bode 频率表头的 CSV。恰好找到一个时自动采用；找到多个或没有找到时，需要显式指定。

### 3.3 选择单个边沿

若波形包含多个脉冲，或者整条记录的首尾不是该边沿的稳定平台，可以限制分析窗口：

```matlab
r = analyze_phase_delay( ...
    ScopeFile="JG22-jg18.mat", ...
    TimeWindow=[-100e-9 500e-9], ...
    OutputDir="results_window");
```

`TimeWindow` 单位始终为**秒**，相对于波形文件的时间零点。窗口必须同时包含输入、输出对应的边沿，并在两端留出足够稳定的平台。上述区间仅为参数示例；改变窗口会改变平台估计，结果可能与默认设置略有不同。

### 3.4 隐藏图窗但保存结果

```matlab
r = analyze_phase_delay( ...
    ScopeFile="JG22-jg18.mat", ...
    Visible="off");
```

程序仍会保存 PNG 和 FIG，保存后关闭隐藏图窗，适合批处理。

## 4. 可配置参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `BodeFile` | 空字符串 | Bode CSV 路径；为空时自动查找唯一匹配文件 |
| `ScopeFile` | 空字符串 | 示波器 MAT/CSV 路径；为空时仅处理 Bode |
| `InputChannel` | `"A"` | 输入通道变量或 CSV 通道名称后缀 |
| `OutputChannel` | `"B"` | 输出通道变量或 CSV 通道名称后缀 |
| `TimeUnit` | `"auto"` | 示波器 CSV 时间单位，支持 s/ms/us/ns/ps；MAT 由 Tinterval 决定 |
| `TimeWindow` | `[-Inf Inf]` | 延迟分析窗口，秒；默认全记录 |
| `PlateauFraction` | `0.15` | 窗口两端分别用于估计平台的比例，须大于 0、小于 0.4 |
| `SmoothSamples` | `1` | 中值平滑窗口，须为正奇数；1 表示不平滑 |
| `OutputDir` | 代码目录下 `results` | 结果目录，不存在时创建 |
| `Visible` | `"on"` | 图窗可见性，使用 `"on"` 或 `"off"` |

`BodeFile`、`ScopeFile`、`OutputDir` 的显式相对路径以 MATLAB 当前目录为基准；它们的默认查找/输出位置以代码所在目录为基准。一键脚本已使用完整路径消除这种差异。

噪声造成重复交点时，可以尝试 `SmoothSamples=3` 或 `5`，但必须检查波形图。平滑可能改变阈值时刻，不应只为了获得某个预期延迟而调整参数。

## 5. 输入文件要求

### 5.1 Bode100 CSV

程序针对当前 Bode100 Gain/Phase 导出格式：分号分隔，允许前面有测量设置说明，数据表头包含：

- `Frequency (Hz)`。
- 带有 `Magnitude (dB)` 的幅值列。
- 带有 `Phase (` 的角度相位列。

频率必须为有限、正值且严格递增，幅值和相位不能有缺失值。存在多条幅值或相位迹线时，当前读取器采用首个匹配列；需要其他迹线时应调整 `read_bode100.m` 或只导出目标迹线。

已经展开到 ±180° 之外的相位会原样保留；仅当全部相位在 ±180° 内时尝试展开。频率采样过稀时，相位圈数可能存在歧义，程序不能凭空恢复丢失的整周信息。

### 5.2 PicoScope MAT

当前读取器要求：

- 通道变量为单条波形的数值向量，例如 `A`、`B`。
- 两通道样本数相同，至少 20 点。
- `Tinterval` 为正的标量采样间隔，单位为秒。
- `Tstart` 若存在，应为标量起始时间，单位为秒；缺省时按 0 处理。
- 波形和时间不能含 NaN、Inf，时间须严格递增。

检查变量：

```matlab
whos('-file','JG22-jg18.mat')
```

程序按通道向量的实际长度构造时间轴，不按 `Length` 字段截断。本次实际通道长度为 5004。多条波形组成的矩阵不被当前读取器接受，应先选定一条记录或分别导出。

### 5.3 PicoScope CSV

支持的典型格式为：

```text
Time,Channel A,Channel B
(ns),(V),(V)
...
```

也支持分号或制表符分隔。第一列是时间，通道表头使用 `Channel A` / `Channel B` 或 `A` / `B`。不能自动识别时间单位时，显式设置：

```matlab
r = analyze_phase_delay(ScopeFile="scope.csv",TimeUnit="ns");
```

电压数据按导出数值读取，不自动进行电压单位换算；阈值按各通道自己的幅度归一化，因此单独的幅度单位缩放不改变阈值延迟。

## 7. 常见问题

| 提示或现象 | 处理方法 |
|---|---|
| 找不到函数或脚本 | 将 `Phase_delay` 设为当前目录，或加入 MATLAB 路径 |
| 要求指定 `BodeFile` | 目录内存在多个或没有匹配的 Bode CSV，传入明确路径 |
| Requested channels missing | 用 `whos('-file',...)` 检查 MAT 通道，或检查 CSV 表头，并调整通道参数 |
| Unknown CSV time unit | 根据实际导出单位设置 `TimeUnit`，不要根据数值大小猜测 |
| No clear settled step | 窗口首尾没有稳定平台，或噪声太大；先查看原始波形，再调整窗口 |
| Multiple/no 50% crossings | 存在多个边沿或噪声重复过阈值；选择单边沿，必要时谨慎平滑 |
| No 10% crossing before 50% crossing | 窗口截掉了边沿前段或基线估计不合适，扩大/移动窗口 |
| Edge overlaps plateau region | 边沿进入首尾平台区，调整窗口或 `PlateauFraction` |
| 延迟为负并有提示 | 检查通道接线和边沿配对；程序保留符号，不会自动交换通道 |
| 传入 `.psdata` 后报错 | 主程序不直接解码专有格式；先转换为 MAT 或 CSV |

程序可能先生成 Bode 图，再在示波器读取或延迟计算阶段报错。应确认命令正常完成并看到本次延迟表，不能仅凭文件夹里存在图片就认定整次分析成功。

## 8. 算法约定与验证

每个通道使用自己的平台定义 10% 和 50%，对阈值附近相邻点做线性插值。延迟为“输出时刻减输入时刻”。延迟相位与校正公式为：

$$
\phi_{\mathrm{delay}}=-360f\tau,\qquad
\phi_{\mathrm{corrected}}=\phi_{\mathrm{measured}}+360f\tau.
$$

其中 $f$ 使用 Hz，$\tau$ 使用秒，相位使用度。阈值延迟可能包含滤波造成的边沿变化，不应自动认定为纯传输延迟。具体物理解释见 `results/分析结果说明.markdown`。

验证程序运行：

```matlab
test_phase_delay
```

测试覆盖已知延迟、极性变化、不同边沿速度、异常波形拒绝、CSV/MAT 单位、原始相位保留和校正符号。测试会使用本次 Bode CSV，并在 `test_results` 中生成或更新合成数据和图片；这些结果不能当作设备实测值。
