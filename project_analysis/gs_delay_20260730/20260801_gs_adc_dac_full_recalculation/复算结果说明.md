## 已确认的数据异常

- `-2dBm.ila.csv` 与 `-5dBm.csv` 的SHA-256完全相同。
- `6dBm.csv` 与 `5dBm.csv` 的SHA-256完全相同。
- `5MHz.ila.csv` 正弦拟合R²约为1.0×10⁻⁶，不参与带宽计算。
- `10MHz.csv` 正弦拟合R²为0.524646，不参与带宽计算；10 MHz采用有效文件 `10Mhz_1.csv`。
- AD766噪声CSV时间列对应416.667 kSPS，不能使用旧脚本中的4.17 MHz固定采样率。

## 目录说明

- `SFDR`：四通道SFDR汇总、频谱图和FIG。
- `Bandwidth`：X3G频率响应汇总和−3 dB带宽图。
- `Isolation`：X3G激励隔离度汇总和结果图。
- `PowerScale`：X3G输入功率响应汇总和结果图。
- `AD766_Linearity`：X9斜坡拟合结果。
- `AD766_Noise`：两个直流码点的PSD/ASD结果。
- `Report_Figures`：测试报告引用的8幅结果图。
- `Logs`：MATLAB运行日志。
